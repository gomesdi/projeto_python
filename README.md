## 📚 Roteiro Detalhado de Conteúdos

### 🔬 1. Fundamentos e Sintaxe Básica
*   **Variáveis e Tipos de Dados:** `str`, `int`, `float`, `bool`.
*   **Operadores:** Aritméticos, de comparação e lógicos.
*   **Entrada e Saída:** Interação com o usuário via `input()` e formatação de texto com `print()` e *f-strings*.

### 🔄 2. Estruturas de Controle e Fluxo
*   **Condicionais:** Tomada de decisão com `if`, `elif` e `else`.
*   **Laços de Repetição:** Iterações estruturadas utilizando `for` e `while`.
*   **Controle de Fluxo:** Uso estratégico de `break` para interromper e `continue` para pular iterações.

### 🗃️ 3. Estruturas de Dados Cavadas
*   **Listas e Tuplas:** Armazenamento sequencial, mutabilidade vs. imutabilidade.
*   **Dicionários:** Estruturas de chave-valor para busca rápida de dados.
*   **Sets (Conjuntos):** Elementos únicos e operações matemáticas de conjuntos (união, interseção).

### ⚙️ 4. Funções e Modularização
*   **Estrutura:** Definição com `def`, parâmetros de entrada e cláusula `return`.
*   **Escopo:** Compreensão de variáveis locais versus globais.
*   **Argumentos Avançados:** Argumentos nomeados, valores padrão, além de empacotamento com `*args` e `**kwargs`.

### ⚡ 5. Comprehensions (Código Sucinto)
*   **List Comprehension:** Criação e filtragem de listas de forma concisa em apenas uma linha.
*   **Dict Comprehension:** Transformação e mapeamento rápido de dicionários dinâmicos.

### 🏛️ 6. Programação Orientada a Objetos (POO)
*   **Classes e Objetos:** O molde (`class`) e as instâncias reais na memória.
*   **Estado e Comportamento:** Atributos para armazenar dados e métodos para ações.
*   **Método Construtor:** Inicialização de variáveis usando o `__init__`.
*   **Herança:** Reutilização de código estendendo classes filhas a partir de classes mães.

### 🛠️ 7. Tratamento de Exceções e Erros
*   **Robustez:** Captura de erros em tempo de execução com blocos `try`, `except` e `finally`.
*   **Customização:** Criação de exceções personalizadas herdando da classe base `Exception`.

### 📂 8. Manipulação de Arquivos
*   **Persistência:** Leitura (`r`) e escrita (`w`/`a`) de arquivos de texto comuns.
*   **Context Manager:** Uso do gerenciador `with` para garantir o fechamento seguro de arquivos automaticamente.

### 📦 9. Módulos e Pacotes
*   **Reutilização:** Importação de códigos usando `import` e `from ... import`.
*   **Organização:** Estruturação de múltiplos arquivos e pastas em pacotes Python estruturados.

### 🌐 10. Ambiente Virtual e Ecossistema
*   **Isolamento:** Criação de ambientes virtuais limpos com o comando `venv`.
*   **Gerenciador de Pacotes:** Instalação de bibliotecas externas através do `pip`.
*   **Reprodutibilidade:** Geração e leitura do arquivo de dependências `requirements.txt`.

## 🛠️ Como Executar os Códigos Deste Repositório

Para rodar qualquer um dos exemplos ou scripts criados durante este estudo, siga os passos abaixo:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/gomesdi/projeto_python.git
   ```
2. **Navegue até a pasta do projeto:**
   ```bash
   cd projeto_python
   ```
3. **Crie e ative seu ambiente virtual:**
   ```bash
   python3 -m venv venv
   # No Linux/macOS:
   source venv/bin/activate
   # No Windows (Prompt de Comando):
   venv\Scripts\activate
   ```
4. **Instale as dependências (caso existam):**
   ```bash
   pip install -r requirements.txt
   ```
5. **Execute um script:**
   ```bash
   python 01.sintaxe_basica.py
   ```
   *(Substitua o nome do script para rodar outros arquivos do repositório).*
